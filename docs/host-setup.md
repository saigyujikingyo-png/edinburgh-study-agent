# Host setup and compatibility

See the maintained [multi-agent setup guide](HOSTS.md) for ChatGPT Work, Claude Desktop/Code, WorkBuddy, official DeepSeek Harness and generic MCP. [Language preferences](LANGUAGES.md) work across clients sharing one person's private data directory.

The server owns a dedicated persistent campus browser and uses structured DOM/direct downloads. No host browser, screenshots or Save As is required. Each user installs independently; private data and sessions survive upgrades and are excluded from public packages. The project does not modify official school records or submit coursework.
