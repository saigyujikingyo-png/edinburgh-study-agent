# 性能与 token 效率 · 0.4.0

2026-09-12，本地 Windows/Python 3.12 合成数据对比，基线为 0.3.0。固定 3,000 条资源、100 次观察、200 条收藏，以及 120 页合成 PPTX；没有真实校园数据。耗时为同一机器 7 次运行的中位数，仍受后台负载影响。

## 本地处理耗时

| 操作 | 0.3.0 毫秒 | 0.4.0 毫秒 | 减少 |
| --- | ---: | ---: | ---: |
| 状态查询 | 37.361 | 2.709 | 92.7% |
| 搜索 20 条 | 62.372 | 10.665 | 82.9% |
| 收藏列表 | 245.364 | 4.735 | 98.1% |
| 个人总览 | 295.257 | 20.222 | 93.2% |
| 重复文档读取 | 4.271 | 2.336 | 45.3% |

首次文档解析单次耗时从 7.151 ms 变为 10.135 ms。新版先解析更多文本以支持随后快速翻页，因此冷读存在开销；不声称每次读取都更快。收藏和总览的默认返回范围更小，不能把全部提升归因于数据库优化。

## MCP 响应大小

计量对象是完整序列化 MCP 返回值，包含兼容性需要的 text 与 structuredContent；使用 `o200k_base` 分词器估算。**这不是 Work 的实际模型账单、上下文 token 或端到端耗时。**

| 响应 | 0.3.0 估算 token | 0.4.0 估算 token | 减少 |
| --- | ---: | ---: | ---: |
| 相同 20 条搜索结果 | 16,119 | 7,241 | 55.1% |
| 个人总览（限制为 10 条任务/收藏） | 32,558 | 6,849 | 79.0% |
| 100 条任务结果的默认响应（新版返回第一页 20 条） | 79,936 | 7,426 | 90.7% |

搜索比较包含相同 20 条结果，只缩短摘要和移除空值。默认任务响应的减少包含分页收益；读取所有页会产生更多输出，不能按第一页比例推算完整任务节省。来源、观察时间、覆盖范围、未知状态和截断标志保留，全文证据仍存于本地，可按需读取。

## 实现与取舍

- 数据库直接筛选、计数、排序和分页，保留 Unicode 搜索；最近观察按来源索引读取。
- 批量查找课程条目，收藏以一个 JOIN 取代逐条数据库连接。
- 文档解析采用进程内 8 项缓存，每项最多约 203 万字符；每次读取仍验证路径和 SHA-256，缓存不掩盖文件变更。
- 已校验本地文件可以直接复用，不启动校园浏览器。需要远端最新版时必须刷新。
- 搜索、收藏和任务结果支持分页；长文默认返回 6,000 字符。agent 根据请求直接选工具，按需取完整数据。
- 任务等待默认 20 秒、最多 25 秒，避免快速重复轮询；没有增设常驻校园浏览器。

## 复现

开发环境额外安装 `tiktoken`，运行 `python scripts/benchmark.py --output benchmark.json`。它创建并清理隔离合成数据库，不读取私有数据。0.3.0 比较应在该版本独立检出上运行同一基准逻辑；使用相同 Python 与依赖，避免同时运行重负载任务。

这些结果不包含校园网络、SSO、网页加载、Work 隧道、模型推理或聊天长度。实际 Work 功能验收单独记录在 [WORK_ACCEPTANCE.md](WORK_ACCEPTANCE.md)。
