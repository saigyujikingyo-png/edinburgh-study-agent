# Share UoE Companion

Share the [public release page](https://github.com/saigyujikingyo-png/edinburgh-study-agent/releases/tag/v0.7.0). Windows x64 students should choose the setup ZIP and follow [Easy installation](EASY_INSTALL.md). The source ZIP is for developers and manual installations.

Each person installs their own backend, connects their own agent and signs in with their own campus account. The Windows installer includes Python and dependencies, merges supported local host configurations and preserves existing account connections. A new ChatGPT account still requires its own private platform connection and permissions.

Do not share your private data directory, browser profile, connection configuration, bound personal plugin copy, downloaded course files or login credentials as an installer. The public bundles contain reviewed source/runtime components, original artwork and upstream licences, without personal campus data.

The product remains a student preview. Core tools, installation, host configuration and actual model workflows have different acceptance boundaries; see [current installation/performance evidence](INSTALL_PERFORMANCE.md), [student workflow coverage](STUDENT_WORKFLOWS.md) and [host evidence](HOSTS.md).

Teachers may try their own permitted resource reading and planning, but staff-only views, grading, rosters and administration are unverified or unimplemented. A student's successful query does not establish teacher support. University email belongs in Outlook and is outside UoE Companion.

When reporting a problem, include the version, host, tool name and a short redacted error description. Do not attach school page bodies, private URLs, account identifiers, profile files, databases or credentials. Use the repository's private security-reporting route for security issues.
