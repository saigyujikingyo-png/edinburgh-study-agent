# 分享 UoE Companion

UoE Companion 优先完善学生版；老师可试用本人有权限的资源读取与个人规划。当前共享单位是源码和安装包：每人拥有自己的本机运行环境、校园会话、资料库和私有 Work 连接。项目没有面向全校的托管服务。

## 发给对方的内容

分享[项目主页](https://github.com/saigyujikingyo-png/edinburgh-study-agent)或[发布下载](https://github.com/saigyujikingyo-png/edinburgh-study-agent/releases)。发布包只包含经检查的代码、说明、测试和原创图标。它不包含开发者的校园数据、下载文件、浏览器资料或连接密钥。

## 新用户的首次配置

1. 在自己的 Windows 电脑安装 Python 3.11+ 和 Google Chrome。
2. 下载发布 zip 并解压，或克隆仓库。在该目录运行 `python scripts/install_runtime.py`。
3. 若使用 ChatGPT 聊天、本地 Work 或云端 Work，按 [Work 连接说明](WORK_SETUP.md)创建自己的私有 Secure MCP Tunnel，并安装、连接唯一的 UoE Companion；三个模式共用此入口，无需再安装同名本机目录条目。所需 Work/隧道权限取决于账户；缺少权限时可使用本地 MCP 主机，但不能将其称为 Work 验收。
   本地 Claude、WorkBuddy 或 DeepSeek Agent 用户按[多智能体接入说明](HOSTS.md)配置，使用同一人的私有资料目录即可复用校园登录。
4. 在 agent 中要求“连接学校”。只在本机插件专属学校窗口输入密码和 MFA。后续请求复用该校园会话。
5. 依次尝试查课程、下载一个文件、读取其文本、加入收藏。检查结果的来源时间和覆盖范围。

电脑需要保持运行，私有连接需要在线。登录策略可要求再次认证。首次连接配置尚未做到通用一键安装。

## 同学与老师

同学可以使用受支持的个人课程、资源、学生记录和个人规划工作流。老师可以试用有权访问的资源读取与个人规划，但教师课程视图、学生名单、评分和其他管理页面尚未验收。批改、发布成绩、考勤和批量学生管理没有实现。不要根据一个学生账号的成功结果推广为教师后台支持。

## 数据边界

不要发送绑定过私人应用的本机插件副本（含 `.app.json`）。分享公开仓库发布包，每位使用者绑定自己的 ChatGPT 连接。不要发送自己的 `~/.edinburgh-study-agent` 目录、私有连接配置、校园登录资料或课程文件作为安装包。每位用户建立独立连接；把作者的私人连接共享出去不会产生用户隔离。Work 会接收为回答请求所需的工具结果和文档摘录，原始下载默认保存在使用者本机。学校记录的写入和发送消息没有实现。

## 升级

停止本人的 Work 连接及其他使用该运行环境的 MCP 客户端后，从新发布源码运行安装器，再恢复连接并在 Work 刷新工具目录。保留现有私有目录即可保留校园会话、收藏、任务和下载。0.5.0 保留旧的内部标识和目录名，因此 `edinburgh-study-agent` 出现在路径中是兼容性安排。源码和运行环境版本可用 `study_status` 核对。

## 问题反馈

在 GitHub 提交问题时提供版本、主机类型、工具名和不含个人数据的错误摘要。去除姓名、学号、课程标识、学校页面正文和私有 URL；不要附浏览器资料或数据库。安全问题使用仓库的私有漏洞报告渠道。
