# Structured school access

The plugin-owned browser implements the live tools. Work does not need browser control. Use the workflow in ../SKILL.md.

Adapters read visible DOM text/links, paginate deferred Learn cards, expand course content and follow observed school navigation. Downloads transfer directly by HTTPS; original file addresses stay internal. No screenshots or coordinate clicks are used.

Legacy host-side capture/download tools remain for compatibility and development. Their existence is not a requirement for normal Work use. Site changes and unsupported external tools must be reported with accurate coverage.
